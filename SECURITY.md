# Security policy

## Supported versions

Only the latest Mac App Store release and the current `main` branch receive security fixes.

| Version | Supported |
| --- | --- |
| Latest App Store release | Yes |
| Older App Store releases | No |
| `main` | Yes |

Topkit requires macOS 14 or later.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Prefer [GitHub private vulnerability reporting](https://github.com/taimansulimani/topkit/security/advisories/new) so we can coordinate a fix before disclosure.

You can also email [hello@topkitapp.com](mailto:hello@topkitapp.com). Include enough detail to reproduce the issue (affected version or commit, steps, and impact).

We will acknowledge reports as soon as we can and keep you updated while we investigate and ship a fix.
